### world model 数据集

1. Two room

   环境就是两个矩形房间，中间一堵墙，墙上有一个门。Agent 是一个红点，从一个房间的随机位置出发，目标是穿过门到达另一个房间的随机位置。动作空间是连续的 2D 位移。

2. PushT 

   一个蓝色圆点（agent）需要把一个 T 形方块推到目标位置和朝向。关键限制是只能"推"，不能抓、不能拉。这意味着 agent 必须绕到 T 形块的合适侧面才能把它推向正确方向。

3. OGbench-cube 

   一个机械臂带末端执行器，需要抓起一个立方体，放到目标位置。看起来简单，但这是从"推"升级到了"抓放"——机器人操作中最基础也最核心的 pick-and-place 任务。

4. Reacher

   一个两段式机械臂固定在平面上，通过控制两个关节的角度，让末端到达目标位置。看起来简单，但这里用的是一个更严格的变体——不是"末端接近目标就行"，而是要求**关节角度完全匹配目标配置**。

**四个 benchmark 合在一起的完整图景：**

| 任务         | 测什么           |
| ------------ | ---------------- |
| TwoRoom      | 环境约束         |
| PushT        | 接触物理         |
| OGBench-Cube | 3D 抓放操控      |
| Reacher      | 机器人自身运动学 |



| 环境         | 数据量          | 轨迹长度 | 训练 epoch | 数据来源                 |
| ------------ | --------------- | -------- | ---------- | ------------------------ |
| TwoRoom      | 10,000 episodes | ~92 步   | 10         | 启发式策略               |
| PushT        | 20,000 episodes | ~196 步  | 10         | 专家数据（沿用 DINO-WM） |
| OGBench-Cube | 10,000 episodes | 200 步   | 10         | benchmark 内置启发式     |
| Reacher      | 10,000 episodes | 200 步   | 10         | SAC 策略                 |



LeWM 完全从像素规划，不使用任何本体感知信息。测试时将起始和目标图像编码到隐空间，用交叉熵方法（CEM）优化动作序列。每帧编码为一个 192 维 token，比 DINO-WM 少约 200 倍，规划在约 1 秒内完成，相比 DINO-WM 的 47 秒实现了 48 倍加速
